Uma rede social de mensagens desenvolvida com Python e Streamlit, com foco em uma experiência simples, limpa e intuitiva para comunicação entre usuários.

🚀 Funcionalidades

- 💬 Lista de conversas
- 👤 Contatos
- 📱 Conversas individuais
- ✉️ Envio de mensagens
- 🕐 Horário das mensagens
- 🔍 Pesquisa de conversas
- 🎨 Interface moderna e responsiva

🛠️ Tecnologias

- Python
- Streamlit
- HTML
- CSS
- 
▶️ Como executar

1. Clone o repositório

git clone https://github.com/SEU-USUARIO/rede-social.git

2. Acesse a pasta

cd rede-social

3. Crie um ambiente virtual

python -m venv venv

4. Ative o ambiente virtual

No Windows:

venv\Scripts\activate

5. Instale as dependências

pip install -r requirements.txt

6. Execute a aplicação

streamlit run app.py

Após executar, a aplicação será aberta no navegador.

📸 Interface

A aplicação possui uma interface inspirada em aplicativos de mensagens, com:

- Navegação entre conversas;
- Lista de contatos;
- Área de mensagens;
- Campo para escrever mensagens;
- Botão de envio.

🎯 Objetivo do projeto

O projeto foi desenvolvido para praticar conceitos de desenvolvimento web com Python, construção de interfaces e organização de aplicações utilizando Streamlit.
